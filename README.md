# Maison Dorée — E-commerce bijoux plaqué or

Boutique React + Tailwind CSS avec expérience mobile-first :

- Catalogue avec filtres (catégorie, prix, nouveautés)
- Recherche dynamique
- Fiche produit (modal)
- Panier modifiable avec total automatique
- Checkout guidé en 3 étapes (client, livraison, paiement simulé)
- Persistance panier via `localStorage`
- Sections prêtes pour newsletter VIP et espace Ads

## Démarrage

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
